# Agent Image Contract

Published benchmark runs execute Codex and Claude Code in caller-supplied,
immutable OCI images. `forgetest` does not publish vendor CLI images because
their installation and redistribution terms are separate from this project.

An agent image must:

- be Linux-based and runnable by an arbitrary non-root UID/GID;
- provide `sh`, `sha256sum`, and the selected `codex` or `claude` executable
  on `PATH`;
- support the noninteractive command generated by the matching built-in
  profile;
- write temporary state below `$HOME` or `/tmp`;
- not require a writable root filesystem; and
- be referenced as `REGISTRY/NAME@sha256:64_HEX_DIGEST` in
  `benchmark.lock.toml`.

At runtime, `forgetest` mounts only the trial workspace at `/work`, creates an
in-memory `/tmp`, sets `HOME=/tmp/home`, drops all Linux capabilities, enables
`no-new-privileges`, applies CPU/memory/PID limits, and removes the container
after the trial. It never mounts the Docker socket or host home.

The outer agent container normally needs outbound network access to call the
vendor API. Only the credential named by the built-in profile is forwarded:
`OPENAI_API_KEY` for Codex or `ANTHROPIC_API_KEY` for Claude Code. The
independent verifier runs later in a different container with no network or
credentials.

Before a benchmark:

```bash
forgetest agents lock \
  --suite eval-suites/rust-agent-v1/suite.toml \
  --agent codex/MODEL=REGISTRY/codex@sha256:DIGEST \
  --agent claude/MODEL=REGISTRY/claude@sha256:DIGEST \
  --verifier-image REGISTRY/forgetest-runner-rust@sha256:DIGEST

forgetest agents doctor --benchmark-lock benchmark.lock.toml
```

`agents lock` and `agents doctor` inspect images without credentials and with
network disabled. They record or verify each CLI version and executable
SHA-256. Authentication checks for host development report only whether the
expected environment variable exists; secret values are never printed.
